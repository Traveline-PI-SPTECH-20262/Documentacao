# ✈️ Traveline

O **Traveline** é uma plataforma web B2B desenvolvida para auxiliar agências de
viagens na análise de dados do setor turístico, transformando informações históricas
em indicadores, gráficos, rankings e recomendações que apoiem a tomada de decisão.

O projeto é desenvolvido como **Projeto Integrador do curso de Análise e
Desenvolvimento de Sistemas da São Paulo Tech School (SPTech)**.

---

## 📌 Sobre o projeto

Agências de viagens precisam analisar grandes volumes de informações para
identificar destinos com maior demanda, períodos de maior movimentação e possíveis
oportunidades comerciais.

Entretanto, esses dados podem estar distribuídos em planilhas e outras fontes,
dificultando sua análise de maneira estruturada.

O Traveline busca facilitar esse processo por meio da importação, tratamento e
armazenamento dos dados, apresentando as informações através de dashboards,
KPIs e recomendações.

Dessa forma, o sistema busca apoiar decisões baseadas em dados em vez de depender
exclusivamente da percepção dos profissionais da agência.

---

## 🎯 Objetivo

Desenvolver uma plataforma web capaz de consumir, tratar e armazenar dados
relacionados ao turismo e transformá-los em informações úteis para agências de
viagens.

A plataforma permitirá:

- Importação de dados através de arquivos `.xlsx`;
- Tratamento e armazenamento dos dados importados;
- Visualização de indicadores e KPIs;
- Visualização de gráficos através de dashboards;
- Aplicação de filtros sobre os dados;
- Identificação de padrões de demanda;
- Análise de períodos de maior movimentação;
- Criação de rankings de destinos;
- Geração de recomendações para apoio à tomada de decisão;
- Geração de notificações relacionadas aos dados analisados;
- Controle de acesso de usuários;
- Registro de atividades relevantes do sistema.

---

## 📊 Base de dados

O projeto utiliza dados disponibilizados pelo **Ministério do Turismo**, através
do **Anuário Estatístico de Turismo**.

Para o desenvolvimento do Traveline foi selecionada a base referente ao
**Anuário Estatístico de Turismo de 2022**, por apresentar informações adequadas
às análises propostas pelo projeto.

Fonte:

https://www.gov.br/turismo/pt-br/acesso-a-informacao/acoes-e-programas/observatorio/anuario-estatistico

O arquivo possui diferentes planilhas com informações que permitem realizar
análises como fluxo turístico, evolução dos indicadores e sazonalidade.

---

## 📈 Análises previstas

A partir dos dados tratados, o Traveline poderá apresentar informações como:

- Destinos com maior movimentação;
- Ranking de destinos;
- Comparação entre destinos;
- Evolução histórica dos indicadores;
- Períodos de maior e menor movimentação;
- Sazonalidade;
- Variações nos indicadores turísticos;
- Recomendações baseadas nos padrões identificados.

Essas informações serão apresentadas principalmente através de **dashboards,
gráficos e KPIs**.

---

## 💡 Recomendações

Além da visualização dos dados, o Traveline busca transformar os indicadores
encontrados em informações úteis para o negócio.

A partir dos padrões identificados, o sistema poderá apresentar recomendações
que auxiliem as agências a identificar destinos que merecem maior atenção.

Exemplo:

> Um destino que apresente crescimento consistente nos dados analisados poderá
> ser destacado como uma possível oportunidade comercial.

As recomendações possuem caráter de **apoio à decisão**, sendo a decisão final
responsabilidade dos profissionais da agência.
