# 🌍 traveline

> Projeto de faculdade - 2adsB - sprint 1 - SaaS B2B desenvolvida para otimizar a criação, organização e gestão em tempo real de agendas de viagens corporativas e de lazer por empresas de turismo.

---

## 📖 Sobre o Projeto

O Treveline é uma solução completa para agências de turismo e operadoras de viagens escalarem suas operações. O sistema centraliza a criação de roteiros personalizados, gestão de reservas de voos/hospedagens, alinhamento de equipes e comunicação com o cliente final em um único painel intuitivo.

Este repositório abriga **toda a documentação oficial**, arquitetura de software, especificações de API e modelos de dados do projeto.
